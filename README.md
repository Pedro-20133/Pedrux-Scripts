## Como obter a key?
1. Execute o Hub dentro de alguma experiencia do Roblox
2. Clique em **Get Key**
3. Cole o link no seu navegador e passe o passo a passo
   
* Você pode colocar a Key diretamente no código ou pode colocar na UI
* Ao colocar a Key uma vez, só será necessário coloca-la novamente quando a Key expirar(24h)
